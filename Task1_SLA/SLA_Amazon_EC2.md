# Соглашение об уровне обслуживания (SLA) Amazon EC2 и Amazon EBS

> Сокращённая версия SLA по облачной вычислительной информационной системе Amazon Elastic Compute Cloud (EC2).
> Оригинал: [Amazon Compute SLA](https://aws.amazon.com/ru/compute/sla/)

## 1. Общие положения

Настоящее соглашение заключается между Amazon Web Services (AWS) и пользователем сервиса Amazon EC2/EBS. AWS обязуется коммерчески разумными усилиями обеспечивать доступность сервиса на уровне не ниже:

- **99,99 %** месячной доступности (Monthly Uptime Percentage) — для инстансов, запущенных **в двух и более зонах доступности** (Availability Zones);
- **99,0 %** — для каждого отдельного инстанса, запущенного **в одной зоне доступности**.

## 2. Ключевые определения

- **Недоступность (Unavailable)** — Amazon EC2 считается недоступным, если все попытки соединения с инстансом в течение минуты завершаются неудачей (не возвращён ни один пакет), при условии корректной настройки инстанса пользователем.
- **Monthly Uptime Percentage** — рассчитывается как: 100 % − доля минут недоступности сервиса в течение календарного месяца.
- **Зона доступности (AZ)** — изолированная площадка внутри региона; каждый регион AWS включает не менее трёх зон.

## 3. Сервисные кредиты

При недостижении заявленного уровня доступности клиенту предоставляется компенсация (сервисный кредит) — процент от ежемесячной платы за сервис:

| Monthly Uptime Percentage (EC2 и EBS, ≥ 2 зон доступности) | Размер кредита |
|---|---|
| < 99,99 % — ≥ 99,0 % | 10 % |
| < 99,0 % — ≥ 95,0 % | 30 % |
| < 95,0 % | 100 % |

| Monthly Uptime Percentage (инстанс в одной зоне доступности) | Размер кредита |
|---|---|
| < 99,0 % — ≥ 95,0 % | 10 % |
| < 95,0 % — ≥ 90,0 % | 30 % |
| < 90,0 % | 100 % |

## 4. Исключения

SLA не применяется к простоям, вызванным:

- плановым техническим обслуживанием, опубликованным заранее;
- ошибками или некорректной конфигурацией со стороны клиента (в т. ч. неправильными настройками безопасности, firewall);
- функциями, находящимися в стадии бета-тестирования (Not Generally Available);
- консолью управления AWS;
- действиями третьих лиц и обстоятельствами непреодолимой силы.

## 5. Порядок получения кредита

1. Заявка подаётся через учётную запись AWS в течение **30 дней** с момента окончания инцидента.
2. Кредиты применяются к будущим платежам за сервис и не могут быть конвертированы в наличные.
3. Предоставление сервисных кредитов является единственным денежным обязательством AWS при нарушении настоящего SLA.
