# Соглашение об уровне обслуживания (SLA) Microsoft 365

> Сокращённая версия SLA по облачной информационной системе Microsoft 365 (Exchange Online, SharePoint Online, OneDrive для бизнеса, Microsoft Teams).
> Оригинал: [Service Level Agreement for Microsoft Online Services](https://www.microsoft.com/licensing/docs/view/Service-Level-Agreement-SLA-for-Online-Services)

## 1. Общие положения

Microsoft гарантирует доступность служб Microsoft 365 на уровне **не менее 99,9 %** времени в течение календарного месяца. SLA является **финансово обеспеченным (financially backed)**: при нарушении гарантии клиент получает сервисные кредиты — возврат части ежемесячной платы.

## 2. Ключевые определения

- **Простой (Downtime)** — период, в течение которого служба недоступна конечным пользователям согласно данным мониторинга и отчётам Microsoft.
- **Доступность (Monthly Uptime)** — рассчитывается по формуле:

  Доступность = (общее число минут в месяце − минуты простоя) / общее число минут в месяце × 100 %

- **Сервисный кредит** — процент от платы за соответствующую службу за месяц, в котором зафиксирован простой.

## 3. Сервисные кредиты

| Ежемесячная доступность | Размер кредита |
|---|---|
| < 99,9 % — ≥ 99,0 % | 25 % |
| < 99,0 % — ≥ 95,0 % | 50 % |
| < 95,0 % | 100 % |

## 4. Исключения

SLA не применяется к простоям, вызванным:

- плановым обслуживанием, о котором Microsoft уведомила заранее (через центр сообщений Message Center);
- проблемами на стороне клиента: оборудование, ПО, сети, неверная конфигурация;
- сторонними приложениями, службами и оборудованием;
- функциями в стадии Preview / Beta;
- превышением лимитов использования, указанных в условиях подписки;
- обстоятельствами непреодолимой силы.

## 5. Порядок получения кредита

1. Заявку подаёт администратор клиента **в течение 30 дней** после окончания месяца, в котором произошёл простой.
2. Кредиты применяются к будущим счётам за подписку; при прекращении подписки — выплачиваются.
3. SLA действует только пока оплата подписки не просрочена.
4. Предоставление кредитов — единственное финансовое обязательство Microsoft при недостижении уровня обслуживания.
